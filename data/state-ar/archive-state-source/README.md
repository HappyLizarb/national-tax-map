# Archived Arkansas source layer

The prior FY2024 state-specific itemized layer is retained here for provenance. It was not added to the Census layer because its accounting scope is not proven disjoint. The active pie uses the Census FY2024 function/category layer so it reconciles to the map ledger.

Original source: https://www.ark.org/dfa/transparency_2024/expenditures.php?do:expenditures&tab=overview
Original source total: $19,953,493,994.30

All 141 agency cards now link to 627 expenditure-classification rows grouped from
the official full FY2024 CSV. The detail files preserve all 233,535 transaction
counts and reconcile exactly to the agency and statewide totals. The 124,777-row
vendor/payee file remains as a same-total alternate statewide grouping because
that export does not carry the agency field.
