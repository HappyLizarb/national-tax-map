# Archived Wyoming source layer

The FY2024 state-specific itemized layer is retained here for provenance. It was not added to the Census layer because WyOpen excludes legally protected and sensitive payments and its WOLFS payment basis is not proven disjoint from, or equivalent to, the Census ledger.

Official search: https://www.wyopen.gov/search
Official limitations: https://www.wyopen.gov/main/readmore
Itemized spending total: $6,548,654,149.67

Twelve bounded monthly exports reproduce all 1,245,917 FY2024 query rows. The 107 agency cards expose 5,268 expenditure-category/description groups from 1,100,556 classified positive line items. Blank-category positive rows and non-positive adjustments remain recorded in the summary reconciliation instead of being netted into the spending hierarchy. The former 17-row ACFR function/activity layer remains linked as non-additive accounting context.
