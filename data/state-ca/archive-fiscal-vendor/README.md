# Archived California vendor layer

These 183 files come from the California Open FI$Cal vendor transaction source at `https://open.fiscal.ca.gov/monthly_vendor_transaction.html`. They are retained as a separate payment layer. The active California pie uses the State Controller FY2023–24 Expenditures Supplement at `https://www.sco.ca.gov/Files-ARD/BudLeg/Expenditures_Supplement_23_24.xlsx`.
