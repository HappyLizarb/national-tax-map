# Archived federal budget-function layer

These FY2024 Treasury MTS budget-function details were the prior federal presentation layer. They remain available for provenance and functional comparison, but the active viewer now uses the additive MTS Table 5 agency/program ledger.

The verified generated datasets are retained as static provenance; the one-off generators were removed.

Source: https://fiscal.treasury.gov/system/files/files/reports-statements/mts/mts0924.pdf
