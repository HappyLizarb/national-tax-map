# Archived Arizona source layer

The FY2024 state-specific layer is retained here for provenance. It was not added to the Census layer because its accounting scope is not proven disjoint. The active pie uses the Census FY2024 function/category layer so it reconciles to the map ledger.

Official source: https://www.azauditor.gov/sites/default/files/2026-04/StateOfArizonaJune30_2024FinancialReport_1.pdf

The General Fund budgetary schedule publishes **913 program rows across 66 agencies totaling $37,497,268,015**, exactly matching its actual-expenditure control. It is a General Fund budgetary layer, not an all-funds or government-wide denominator. The prior 12-row ACFR function/activity layer totaling $62,548,895,000 remains linked as non-additive context.
