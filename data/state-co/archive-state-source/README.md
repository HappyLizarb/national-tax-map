# Archived Colorado source layer

The FY2024 state-specific itemized layer is retained here for provenance. It was not added to the Census layer because TOPS excludes transfers and adjustments and its payment scope is not proven disjoint from, or equivalent to, the Census ledger.

Official source: https://data.colorado.gov/stories/s/TOPS-Expenses/pqw4-6m8r/
Official crosstab: https://tableau.state.co.us/t/DPA_TOPS/views/TOPSExpenses/TOPSExpenses
Itemized source total: $39,210,596,217.87

Twelve bounded month exports preserve 1,033,925 FY2024 transactions. The 24 department cards expose all 2,577 expense-code groups and reconcile exactly to the exported rows. The former 16-row ACFR function/activity layer remains linked as non-additive accounting context.
